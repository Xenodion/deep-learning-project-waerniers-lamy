# nlp

The natural-language part of the guide (answering visitor questions such as "Which painting shows a stormy sea?"): an experimental
multimodal recommendation ladder, E0 to E5. The decision is in [ADR 0005](../../../adr/0005-nlp-recommendation-ladder.md), the plan in
[EXPERIMENT_PLAN.md](EXPERIMENT_PLAN.md), and the results in `results/nlp_experiments.csv`.

It follows the same museum A / museum B protocol as the vision work ([ADR 0003](../../../adr/0003-simulated-museum-b-test-set.md)).
